# e-plantShopping

## Paradise Nursery Shopping Application

This is the front-end React application for Paradise Nursery, an online plant shop. 

### Features:
- Landing page with an engaging background and "Get Started" button.
- Product listing page with plants grouped into categories.
- Dynamic shopping cart using Redux Toolkit.
- Increase, decrease, and delete functionality for cart items.
- Total cost and item quantity calculations.
- Responsive and modern UI design.

### Technologies Used:
- React.js
- Redux Toolkit
- React Router
- CSS3
